# Wavever Tap

Official Homebrew Tap for [Clipth (剪迹)](https://clipth.app) and tools by [Wavever](https://github.com/wavever).

## Installation

```bash
brew install wavever/tap/clipth
```

Or tap first:

```bash
brew tap wavever/tap
brew install --cask clipth
```
